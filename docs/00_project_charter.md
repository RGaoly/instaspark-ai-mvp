# Project Charter

## 项目目标

用一个可运行、可解释、可评测的 MVP，证明 AI 可以把新品任务转化为达人推荐和本地化合作 Brief。

## 一期不做

- 完整达人 CRM
- 自动发信与合同支付
- 全平台爬虫
- 真实广告归因
- 自动预算执行
- 企业级权限与多租户

## 黄金链路

1. 用户选择产品、市场和场景。
2. 系统对候选达人进行硬门槛过滤。
3. 系统按五个维度计算匹配分。
4. 系统展示正向证据、反向证据和风险。
5. 用户采纳或驳回，填写 Reason Code。
6. 系统生成本地化合作 Brief。
7. 决策记录进入日志，为后续评测和学习提供数据。

## 成功标准

- 任何人可在 10 分钟内本地运行。
- 每个推荐都有分项得分和文字解释。
- 评分逻辑有单元测试。
- 数据来源和限制清楚标注。
- README、PRD、架构和评测文档完整。
